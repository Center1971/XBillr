Hilfe - Rechnungen

info Übersicht

Auf dieser Seite können Sie alle Ihre Rechnungen verwalten. Die Rechnungen werden automatisch aus den erfassten Zeiteinträgen generiert und können als PDF oder XRechnung-XML exportiert werden.

add_circle Neue Rechnung erstellen

  1. Klicken Sie auf den Button "Neue Rechnung"
  2. Wählen Sie einen Kunden aus der Liste aus
  3. Geben Sie den Leistungszeitraum (Von/Bis Datum) ein
  4. Wählen Sie den Steuertyp (MwSt, keine MwSt, Reverse Charge)
  5. Der MwSt-Satz wird automatisch vom Kunden übernommen, kann aber angepasst werden
  6. Geben Sie optional das Zahlungsziel in Tagen ein
  7. Optional: Aktivieren Sie "Stundenzettel an Rechnung anhängen"
  8. Klicken Sie auf "Rechnung erstellen"

Hinweis: Die Rechnung wird automatisch aus allen Zeiteinträgen des gewählten Zeitraums für den ausgewählten Kunden erstellt. Tagessätze und Stundensätze werden als separate Positionen gruppiert.

search Rechnungen suchen

Verwenden Sie das Suchfeld, um nach Rechnungen zu suchen. Sie können nach folgenden Kriterien suchen:

  • Rechnungsnummer
  • Kundenname
  • Datum
  • Betrag
  • Status (Entwurf, Archiviert)

visibility Rechnung anzeigen

Klicken Sie auf das visibility Icon in der Aktionsspalte, um die Details einer Rechnung anzuzeigen. Sie sehen alle Positionen, Summen und Steuerinformationen.

picture_as_pdf PDF exportieren

Klicken Sie auf das picture_as_pdf Icon, um die Rechnung als PDF herunterzuladen. Die PDF enthält alle Rechnungsdetails im korrekten Format mit Rechnungssteller, Kunde, Positionen, Summen und Steuerinformationen.

Tipp: Wenn Sie beim Erstellen der Rechnung "Stundenzettel an Rechnung anhängen" aktiviert haben, wird der Stundenzettel automatisch als zusätzliche Seite an die PDF-Rechnung angehängt.

code XRechnung XML exportieren

Klicken Sie auf das code Icon, um die Rechnung im XRechnung-Format (UBL 2.1) als XML-Datei herunterzuladen. Dieses Format entspricht dem deutschen Standard für elektronische Rechnungen und kann direkt an Behörden oder Unternehmen übermittelt werden.

archive Rechnung archivieren

Klicken Sie auf das archive Icon, um eine Rechnung zu archivieren. Archivierte Rechnungen bleiben in der Liste sichtbar, können aber nicht mehr bearbeitet werden. Sie können archivierte Rechnungen wieder aktivieren, indem Sie auf das unarchive Icon klicken.

edit Rechnung korrigieren

Archivierte Rechnungen können korrigiert werden. Klicken Sie auf das edit Icon bei einer archivierten Rechnung, um eine Korrektur zu erstellen. Die korrigierte Rechnung erhält automatisch die Original-Rechnungsnummer mit dem Zusatz "-KOR".

content_copy Rechnung duplizieren

Klicken Sie auf das content_copy Icon, um eine Rechnung zu duplizieren. Die duplizierte Rechnung kann dann bearbeitet werden.

delete Rechnung löschen

Klicken Sie auf das delete Icon, um eine Rechnung zu löschen. Diese Aktion kann nicht rückgängig gemacht werden.

lightbulb Tipps

  • Stellen Sie sicher, dass alle Zeiteinträge für den gewählten Zeitraum erfasst sind, bevor Sie eine Rechnung erstellen
  • Überprüfen Sie die Rechnungsdetails vor dem Archivieren
  • Archivierte Rechnungen können nicht mehr bearbeitet werden - verwenden Sie die Korrektur-Funktion für Änderungen
  • Die Rechnungsnummer wird automatisch generiert (Format: RE-YYYY-NNN)
  • Das Zahlungsziel wird automatisch basierend auf den Kundeneinstellungen berechnet

Lade archivierte Rechnungen...
Hilfe - Archiv

info Übersicht

Im Archiv werden alle archivierten Rechnungen angezeigt. Archivierte Rechnungen können nicht mehr bearbeitet werden, können aber weiterhin angezeigt, exportiert, dearchiviert oder korrigiert werden.

search Rechnungen suchen

Verwenden Sie das Suchfeld, um nach archivierten Rechnungen zu suchen. Sie können nach folgenden Kriterien suchen:

  • Rechnungsnummer
  • Kundenname
  • Datum
  • Betrag

visibility Rechnung anzeigen

Klicken Sie auf das visibility Icon, um die Details einer archivierten Rechnung anzuzeigen. Sie sehen alle Positionen, Summen und Steuerinformationen.

picture_as_pdf PDF exportieren

Klicken Sie auf das picture_as_pdf Icon, um die archivierte Rechnung als PDF herunterzuladen.

code XRechnung XML exportieren

Klicken Sie auf das code Icon, um die archivierte Rechnung im XRechnung-Format (UBL 2.1) als XML-Datei herunterzuladen.

unarchive Rechnung dearchivieren

Klicken Sie auf das unarchive Icon, um eine archivierte Rechnung wieder zu aktivieren. Die Rechnung wird dann aus dem Archiv entfernt und kann wieder bearbeitet werden.

edit Rechnung korrigieren

Klicken Sie auf das edit Icon, um eine Korrektur-Rechnung zu erstellen. Die korrigierte Rechnung erhält automatisch die Original-Rechnungsnummer mit dem Zusatz "-KOR" und wird als neue Rechnung erstellt.

Hinweis: Die Original-Rechnung bleibt im Archiv. Die Korrektur-Rechnung wird als neue, nicht-archivierte Rechnung erstellt.

lightbulb Tipps

  • Archivierte Rechnungen können nicht mehr direkt bearbeitet werden
  • Verwenden Sie die Korrektur-Funktion, um Fehler in archivierten Rechnungen zu beheben
  • Dearchivierte Rechnungen erscheinen wieder in der normalen Rechnungsliste
  • Das Archiv dient der langfristigen Aufbewahrung abgeschlossener Rechnungen
